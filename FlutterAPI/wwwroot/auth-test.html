cURL Examples

Login with cURL: 
curl -X POST "http://localhost:5000/api/Authentication/UserLogin" \
  -H "Content-Type: application/json" \
  -d '{"userEmail": "student@university.edu", "userPassword": "SecurePassword123!"}'
Authenticated Request with cURL: 
curl -X GET "http://localhost:5000/api/Dashboard/ShowForStudents/1" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN_HERE"

Troubleshooting Guide

Common Issues

401 Unauthorized Errors

  • Missing Token: Ensure Authorization header is included
  • Wrong Format: Token must start with "Bearer "
  • Expired Token: Login again to get a fresh token
  • Invalid Token: Check token was copied correctly

403 Forbidden Errors

  • Wrong Role: Check if your user role has required permissions
  • Endpoint Restrictions: Some endpoints require specific roles
  • Token Claims: Verify token contains correct role information

Login Issues

  • Account Not Found: Register the account first
  • Wrong Password: Check password requirements and spelling
  • Email Format: Ensure email is in correct format
